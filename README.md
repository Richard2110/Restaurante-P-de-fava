# 🍽️ Pé de Fava - Calculadora de Conta

Aplicativo Android desenvolvido para facilitar a divisão de contas de restaurante entre amigos, calculando consumos individuais, couvert artístico e taxa de serviço.

---

## 📱 Funcionalidades

- **Cálculo de Consumo:** Inserção do valor total consumido na mesa.
- **Couvert Artístico:** Campo opcional para inclusão do couvert.
- **Taxa de Serviço:** Adição automática de 10% de taxa sobre o consumo.
- **Divisão da Conta:** Rateio automático do valor final pelo número de pessoas informadas.
- **Interface Intuitiva:** Layout simples e responsivo com ScrollView para suporte a diferentes tamanhos de tela.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java
- **UI/Layout:** XML (LinearLayout, ScrollView)
- **IDE:** Android Studio
- **Versão Mínima do SDK:** Android 8.0 (API level 26) ou superior
